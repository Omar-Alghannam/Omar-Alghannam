### Featured Projects

#### [CineMatch AI](https://github.com/Omar-Alghannam)
*AI-powered movies recommendation engine utilizing state-of-the-art embedding and collaborative filtering models.*
- **Core Focus:** Built using SBERT (Sentence-BERT) embeddings for semantic understanding and Singular Value Decomposition (SVD) for matrix factorization collaborative filtering.
- **Tech Stack:** `FastAPI` • `PyTorch` • `Supabase` • `SBERT` • `SVD`

#### [Football Search Engine](https://github.com/Omar-Alghannam)
*A high-performance semantic search platform queryable with natural language for football datasets.*
- **Core Focus:** Implemented hybrid lexical (TF-IDF) and semantic (Word2Vec) retrieval to return relevant matches and player information, querying web data with SerpAPI and serving it with Streamlit.
- **Tech Stack:** `Python` • `DuckDB` • `Streamlit` • `Word2Vec` • `SerpAPI`

#### [Gemma-4 Fine-Tuning Pipeline](https://github.com/Omar-Alghannam)
*An enterprise-grade, high-throughput model optimization workflow designed for production-scale fine-tuning.*
- **Core Focus:** Built LoRA-based fine-tuning architecture leveraging HuggingFace PEFT, NVFP4 quantization, and optimized inference serving using vLLM for paid client work.
- **Tech Stack:** `LoRA` • `PEFT` • `NVFP4` • `vLLM` • `HuggingFace`

#### [Premier League Analytics Dashboard](https://github.com/Omar-Alghannam)
*An interactive data visualization suite detailing team and player performance stats.*
- **Core Focus:** Interactive and responsive visualization of live Premier League metrics using AmCharts 5 for clear storytelling.
- **Tech Stack:** `TypeScript` • `React` • `Tailwind CSS` • `AmCharts 5`

#### [Mowasla](https://github.com/Omar-Alghannam)
*An Uber-like ride-hailing desktop/web ecosystem focusing on routing and driver matchmaking.*
- **Core Focus:** Designed a robust relational database schema and client matching logic to handle transactions, geo-spatial lookups, and driver allocation.
- **Tech Stack:** `C#` • `SQL Server` • `ADO.NET`
